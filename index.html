Cek stok (browser -> Kong REST -> gRPC service)

Ini memanggil GET /v1/stock/{sku} dengan header X-Company-Id di Kong (port 8000). Kong men-transcode request JSON ini jadi call gRPC ke inventory-service, lalu hasilnya di-encode balik jadi JSON di sini. Tidak ada kode gRPC apa pun di halaman ini — browser tidak pernah bicara gRPC langsung.
