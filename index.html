Cek stok (browser -> Kong REST -> gRPC service)

Halaman ini memanggil GET /v1/stock/{sku} dengan demo apikey di Kong (port 8000). Kong memvalidasi key, menentukan Consumer, lalu men-transcode HTTP GET menjadi call gRPC ke inventory-service. Demo key ini publik dan hanya untuk stack lokal.
